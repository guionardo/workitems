# Architecture Decision Records

This directory records the project's relevant architectural decisions.

## Convention

- Files use the `NNNN-short-title.md` format.
- Accepted ADRs must not be deleted; when a decision changes, create a new ADR that supersedes it.
- Each ADR must record context, the decision, and consequences.
